# Before publishing

- [ ] Copy `deploy-pages-workflow.yml` to the repository root at `.github/workflows/puzhub-site.yml`.
- [ ] Push to GitHub and enable **Settings → Pages → GitHub Actions**.
- [ ] Confirm the published URL is public, HTTPS, and loads `privacy-policy.html` without sign-in or geographic restrictions.
- [ ] Test every page and link on phone and desktop; check both themes.
- [ ] Update the app’s in-app privacy entry to open the final public privacy URL.
- [ ] Add that same public URL in the Google Play Console.
- [ ] Review the final release AAB, merged manifest, and all SDK behavior; complete Data safety accurately.
- [ ] Review age rating, target audience, permission declarations, and listing claims against the exact build.
